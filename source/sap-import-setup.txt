ROUTE PLANNER - SAP DESKTOP IMPORT (MACRO)

This copies your call list from SAP GUI (SAP Logon 800) so you can paste it
straight into the online Route Planner - no retyping.

The macro only READS SAP and copies text to your clipboard. It does not write
files, open programs, or send anything anywhere.

----------------------------------------------------------------------
ONE-TIME SETUP

1) TURN ON SAP GUI SCRIPTING (required)
   - On your PC: SAP Logon -> Options (Alt+F12) -> Accessibility & Scripting
     -> Scripting -> tick "Enable scripting". Un-tick both "Notify when a
     script..." boxes so it doesn't prompt every time.
   - On the server: this needs profile parameter sapgui/user_scripting = TRUE.
     If scripting stays greyed out or you get "Scripting is disabled by the
     server", Basis/IT has to switch it on (a quick RZ11 change).

   10-SECOND TEST: press Alt+F12 in SAP. If "Script Recording and Playback"
   opens and the red Record button works, scripting is on.

2) SAVE THE MACRO
   The download comes as a .zip (browsers block .vbs downloads directly).
   Right-click the zip -> Extract All, then put Import_to_RoutePlanner.vbs
   somewhere handy - the Desktop is fine.

   IF ANTIVIRUS FLAGS OR BLOCKS IT (common on work PCs for downloaded scripts):
   Make the file yourself instead - a file you type locally is not treated as a
   download and is almost never flagged:
     a. Open Notepad.
     b. Paste the macro text (from the Route Planner page: SAP import ->
        "Show macro text", or ask for it).
     c. File -> Save As. Set "Save as type" to All files, name it
        Import_to_RoutePlanner.vbs, Encoding UTF-8, and save it to your Desktop.
   If it's still blocked, the macro can also be run from inside SAP:
   Alt+F12 -> Script Recording and Playback -> open the .vbs -> Play.
   As a last resort, ask IT to allow this one script.

----------------------------------------------------------------------
USING IT EACH DAY
  1. Sign into SAP Logon (system 800).
  2. Run IW49N and let your call list display (your usual selection/variant).
  3. Run Import_to_RoutePlanner.vbs (double-click, or Alt+F12 -> Playback).
     -> A box says "Copied N calls."
  4. Open the Route Planner, click the "Paste service call rows" box,
     press Ctrl+V, then select "Load calls".
     -> Your whole call list is replaced.

----------------------------------------------------------------------
IF SOMETHING DOESN'T WORK
The macro shows a short message naming the step that failed:
  - "SAP GUI isn't running / scripting can't reach it" -> scripting is off
    (do step 1), or SAP isn't open.
  - "No service-order list found" -> run IW49N and let the list display first.
  - "Couldn't find the Order column" -> your IW49N layout names columns
    differently. Note the column titles across the top of the list.

GOOD TO KNOW
  - It reads whatever list is on screen, so you can filter/sort in IW49N first
    and only the rows you see get copied.
  - Pasting replaces the Planner's whole list, so completed calls drop off.
  - Desktop only (SAP GUI). It is not for phones.
