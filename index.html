Service Route Planner

Plan your day of service calls: paste your calls, see them grouped by store, and get a driving order with Google Maps directions. Use it online in your browser, or download it to use with no internet. Nothing to install, and your data stays on your device.

Save the file yourself

This window can't save files directly, usually because it isn't signed in to Claude. You can also get every edition from GitHub, or copy the file here:

  1. Select Copy file below.
  2. Open Notepad (Windows) or TextEdit (Mac, set to plain text with Format > Make Plain Text) and paste.
  3. Save it as . In Notepad, set "Save as type" to All files and Encoding to UTF-8.
  4. Double-click the saved file to open it in Edge or Chrome.

Getting started

  1. Use online to open the planner right in your browser on any phone or computer, or Download the version for your area. Save it somewhere easy to find, like your desktop.
  2. If you downloaded it, open the file in Microsoft Edge or Chrome by double-clicking it. It works offline.
  3. Paste your service calls into the Import box and select Load calls. Mark calls Done as you finish them.

Your data is saved in your browser, so closing and reopening the file keeps your calls, completed list, and settings. To move to another computer, use Save backup file in the planner.

When a new version comes out, download it and open it in the same browser. Your saved data carries over to the new version of the same edition.
