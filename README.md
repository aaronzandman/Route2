# Route2 – Service Route Planner

Plan a day of service calls: paste calls, see them grouped by store, filter by how long they're past due, and get a driving order with Google Maps directions. Each planner is a single HTML file that runs offline; saved data stays in the browser on that device.

- `index.html` – download page with every edition (works offline)
- `planners/` – one file per edition: company-wide, AL, FL, GA, KY, NC, SC, TN, VA
- `source/` – shared planner source, store list, and the build script that makes every edition

Current version: 2.2
